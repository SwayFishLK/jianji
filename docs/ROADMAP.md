# 简记 · 路线图

> 受青简启发、纯 Kotlin 实现的安卓拼音输入法。
> 决策记录见文末"已定决策"。

## 里程碑

| 阶段 | 内容 | 验收标准 | 状态 |
|---|---|---|---|
| **M0** | 环境（`.dev-env` 工具链）+ 工程骨架 + 空壳 IME | 真机安装 APK，切换到简记，显示占位视图 | 已完成（2026-10-16 真机验证） |

### 二期备选

- 九宫格（T9）键盘
- 整句输入（bigram Viterbi，数据可从青简语言模型裁剪）
- 双拼、模糊音、拼写纠错
- 输入统计页（极简）

## 已定决策（2026-10-16）

1. **候选区布局 = 方案 A**：候选格双行，译文小字在上（~10sp 灰）、候选大字在下；
   横向滑动；拼音内联显示在输入框（不占键盘高度）。
2. **引擎 = 纯 Kotlin 自研**：无 NDK；引擎接口化（`PinyinEngine`），未来可替换实现。
3. **首发键盘 = 仅 26 键**；九宫格二期。
4. **许可 = GPL-3.0-or-later**，复用青简词库/释义表/等级表（GPL 数据），
   应用内与 `NOTICE` 同步署名。
5. **名称 = 简记（Jianji）**；不使用"青简"名称与 logo（不在其开源许可范围内）。
6. **发布签名（M5）**：`keystore/jianji-release.jks` + `keystore.properties`（RSA 4096）；debug 与 release 共用
   同一密钥（互相覆盖安装不丢数据）；两者都不进版本库，需**自行备份**（丢失后无法覆盖升级）。
7. **字体与图标（M5.1 用户拍板）**：候选字体 = **跟随系统**（M5 的文楷子集试作已从 APK 撤出，
   管线留档 `tools/fontgen/`）；应用图标 = 方案 B「墨底蓝简」（`tools/icon/gen_icon.py` 生成，
   自适应 + 传统图标）；设置系页面（设置/许可）= 卡片风格（`ImUi.kt` 共用样式 + `res/drawable/ic_*.xml` 矢量图标）。
