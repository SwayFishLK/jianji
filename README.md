# 简记（Jianji）

> 安卓输入法。好好打字，顺便多认识一个词。

简记是一个受[青简（Qingjian）](https://github.com/qingjian-team/qingjian)启发的安卓拼音输入法：
候选词旁附带英语 / 日语译词，让语言学习自然发生在日常输入里。

## 产品原则

- **输入优先**：翻译只是辅助信息，永不阻塞候选生成。
- **一次一种语言**：英语或日语，可随时关闭。
- **轻量做减法**：不塞语音、手写、皮肤商店、云同步、资讯。
- **本地优先**：拼音引擎、词库、学习记录全部在本机完成。
- **零联网**：不申请网络权限，所有数据只在本机。

## 主要特性

- 26 键拼音（全拼 / 简拼），二期九宫格
- 双行候选：译文小字在上、候选大字在下
- 候选上划上屏译文；字母键上滑直接打数字 / 符号
- 生词高亮、词频与搭配记忆（常用词前置、刚打过的优先）
- 自造短语记忆：同一串重复上屏 3 次后，全拼 / 简拼 / 混着打都能整串出候选，记忆只增不减
- 中文模式英文提示：输入 `hello` / `python` 这类明显英文时，候选栏最多给 1 个最可能的词（不抢拼音首选）
- 首选词 emoji：`开心` 后跟一个 😄（只跟首选词、整段吃满才出，最多 1 个）
- 模糊音（平翘舌 / 前后鼻音 / n-l）、空格横滑移动光标
- 剪贴板（含常用语置顶）、精简符号面板
- 深色默认主题；候选字体跟随系统；卡片式设置页（图标「墨底蓝简」）

## 工程结构

```
app/        安卓应用（输入法本体）
tools/      数据管线（词库/释义表打包、图标生成；字体子集管线留档）
docs/       方案与路线图
reference/  外部参考仓库（不打包）
.dev-env/   临时开发环境（项目完成后可整体删除）
```

## 构建

```powershell
# 环境在 .dev-env 内（JDK / Android SDK / Gradle / Git）
. .\.dev-env\env.ps1
.\gradlew.bat :app:assembleDebug
```
